# LTB Case Finder

A case discovery tool that helps Ontario residential tenants find past Landlord and Tenant Board (LTB) orders related to their rental issue — without needing to know LTB legal terminology or application codes.

## The Problem

Ontario tenants dealing with a rental issue (unpaid maintenance, an eviction notice, a rent dispute, etc.) often don't know that a public catalogue of past LTB decisions exists, and even if they find it, the catalogue is organized by legal application codes (`T2`, `L1`, `A4`...) that aren't meaningful to someone without legal training. LTB Case Finder closes that gap: a tenant describes their issue in plain language, and the tool surfaces relevant past orders for them to read.

**This is a research tool, not legal advice.** It does not determine outcomes, does not interpret orders, and does not guarantee that a similar past decision will apply to any individual's situation. See [Scope & Legal Boundaries](#scope--legal-boundaries).

## Status

**MVP 0 — In Development.** MVP 0 covers structured, metadata-based search only (no free text, no AI). See [`docs/mvp0/plan.md`](docs/mvp0/plan.md) for the full spec and [`docs/mvp0/tasks.md`](docs/mvp0/tasks.md) for the build backlog.

## How It Works

1. The tenant selects one or more issue categories from a predefined list.
2. The app finds LTB orders whose application codes match the selected categories.
3. Cases matching **all** selected categories are prioritized; if fewer than 20 exist, cases matching **at least one** category fill the remaining slots.
4. Results are ordered by most recent order date, capped at **20 cases**.
5. The tenant can open the original order document for any result.

## Issue Categories

The interface presents these user-facing categories (backed by official LTB application codes internally — see [`config/issue_taxonomy.json`](config/issue_taxonomy.json)):

* Rent and Payment
* Tenancy Eviction
* Tenancy Ending
* Notice
* Breached Conditions
* Rent Change
* Maintenance
* Care Home Tenancies
* Locks and Access
* Tenancy Agreements
* Tenant Rights
* Suite Meters
* Co-op Housing
* Arrears

## Results

Each result displays:

| File Number | Order Date | Issues | City | Document Type | View Order |
| ----------- | ---------- | ------ | ---- | -------------- | ---------- |

The `Issues` column shows human-readable category names (e.g. `Maintenance · Tenant Rights`) rather than raw application codes — the codes are used internally for filtering and ranking only.

## Data Source

[Ontario Open Data — LTB Order Catalogue](https://data.ontario.ca/). The app uses this catalogue's metadata (file number, order date, application codes, city, document type, document URL) to find and link to orders. It does not download, parse, or analyze the contents of the order PDFs themselves — `View Order` links straight to the source document.

## Getting Started

> The ingestion pipeline and backend are still being built (see [`docs/mvp0/tasks.md`](docs/mvp0/tasks.md)). This section describes the intended local setup and will be kept accurate as each piece lands.

**Prerequisites:** Python 3.11+

1. **Install dependencies**
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. **Build the local database** — runs the ingestion pipeline against the raw catalogue snapshot in `data/raw/`, applies the issue taxonomy mapping, and writes `data/ltb.db`:
   ```
   python scripts/ingest.py
   ```
   (This is a standalone script, separate from the FastAPI app — see [`docs/mvp0/architecture.md`](docs/mvp0/architecture.md#21-data-pipeline-offline).)
3. **Start the backend API**
   ```
   uvicorn backend.main:app --reload
   ```
4. **Open the frontend** — open `frontend/index.html` directly in a browser (MVP 0 has no frontend build step).

Run the test suite with:
```
pytest
```

## Scope & Legal Boundaries

MVP 0 is intentionally limited. It does **not**:

* Analyze order documents (no PDF parsing, no OCR)
* Use TF-IDF, cosine similarity, or any LLM
* Provide legal advice, predict case outcomes, or recommend legal action
* Interpret an order or claim a past decision will apply to a user's situation
* Require user accounts or authentication
* Return more than 20 results per search

The application exists to help tenants **find relevant LTB orders for further research** — not to determine the outcome of their own case.
